# Triple Espresso

Triple Espresso é um projeto web para uma cafeteria moderna, desenvolvido para apresentar o cardápio, receitas e opções de reserva de forma visualmente atraente e fácil de usar. O projeto possui um layout limpo, design responsivo e estrutura modular de CSS para facilitar a manutenção e a escalabilidade.

## Funcionalidades

- Página inicial estilosa com identidade visual da cafeteria
- Seções de cardápio e receitas
- Formulário de reserva para clientes
- CSS modular para fácil personalização
- Design responsivo para todos os dispositivos

## Estrutura de Pastas

- `blocks/` – Arquivos CSS para diferentes seções (cabeçalho, rodapé, receitas, etc.)
- `images/` – Imagens do site
- `pages/` – CSS adicional para páginas específicas
- `vendor/` – CSS de terceiros (ex: normalize.css)
- `index.html` – Arquivo HTML principal

## Pontos de Melhoria

- Tornar o site totalmente responsivo
- Adicionar funcionalidades em JavaScript

## Como começar

1. Clone ou baixe o repositório.
2. Abra o arquivo `index.html` no navegador para visualizar o site.
3. Personalize o conteúdo e os estilos conforme necessário.
